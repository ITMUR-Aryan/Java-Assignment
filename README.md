## 📚 Table of Contents

| Practical | Title | Topic / Description | Source File(s) |
|:---:|:---|:---|:---|
| [01](src/Practical-1/) | Matrix Multiplication | Matrix multiplication using InputStreamReader and BufferedReader | `MatrixMultiplication.java` |

| [03](src/Practical-3/) | AWT Calculator | Calculator using Java AWT controls | `Calculator.java` |
| [04](src/Practical-4/) | Client-Server Communication | TCP communication using ServerSocket and Socket | `MyServer.java`, `MyClient.java` |

| [09](src/Practical-9/) | Student Registration Portal | Student record management using CRUD operations | `StudentRegistration.java` |
| [10](src/Practical-10/) | JavaBean Addition | Addition of two numbers using JavaBean | `AdditionBean.java`, `AdditionDemo.java` |
| [11](src/Practical-11/) | Login Form | Login form using Java Swing | `LoginApplet.java` |
| [12](src/Practical-12/) | CRUD Operations | Create, Read, Update and Delete operations using CSV storage | `StudentCRUD.java` |
