# Practical 6 - Remote Method Invocation (RMI)

## Question
Create functions like multiplication, addition, and subtraction respectively. Invoke these functions from a remote system by using the concept of Remote Method Invocation in Java.

## Language
Java

## Program Files
- `RemoteCalc.java` - Remote interface
- `RemoteCalcImpl.java` - Implementation of remote methods
- `RMIServer.java` - RMI server program
- `RMIClient.java` - RMI client program

## Description
This program demonstrates Remote Method Invocation (RMI) in Java. It allows a client to invoke remote methods on the server to perform addition, subtraction, and multiplication of two numbers.
