# Practical 7 - Registration Form Using Java Swing

## Question
Create a form containing fields Name and Password respectively, using Applet as a container.

## Language
Java

## Program File
`LoginPageN.java`

## Description
This program creates a registration form using Java Swing. It contains Name and Password fields along with a Submit button. It validates the input fields and saves the entered data into a CSV file named `users.csv`.
