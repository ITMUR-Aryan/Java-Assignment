# Practical 10 - Addition Using JavaBean

## Question
Write a program to create a Bean component in Java for addition of two numbers.

## Language
Java

## Program Files
- `AdditionBean.java`
- `AdditionDemo.java`

## Description
This program creates a JavaBean component named `AdditionBean` to perform addition of two numbers. It uses private variables, setter methods, and a getter method to calculate and return the sum. The `AdditionDemo` class takes input from the user and displays the addition result.
