# Practical 02: String Animation Using Multithreading in Java

## Question
Write a Java program to display an animated string using multithreading.

## Technologies Used
- Java
- IntelliJ IDEA
- Java Swing

## Concepts Used
- Multithreading
- Thread Class
- Runnable Interface
- Swing Components
- Graphics Class
- Exception Handling
- Thread.sleep()

## How to Run (Using IntelliJ IDEA)

1. Open IntelliJ IDEA.
2. Open the Java project.
3. Navigate to `Practical-2`.
4. Open `StringAnimation.java`.
5. Right-click inside the code editor.
6. Select **Run 'StringAnimation.main()'**.
7. The animation window will appear.
8. Observe the string moving across the window.

## Expected Result

The program displays the text **"Welcome to Java"** in blue color. The string moves horizontally across the window using multithreading.
