# Practical 2 - String Animation Using Multithreading

## Question
Write a program to animate a string on an Applet using the concept of multithreading.

## Language
Java

## Program File
`StringAnimation.java`

## Description
This program animates the string "Welcome to Java" using Java Swing and multithreading. The Runnable interface and Thread class are used to move the string across the window repeatedly.
