# Practical 01: Matrix Multiplication in Java

## Question
Write a program for matrix multiplication. Use InputStreamReader and BufferedReader classes for Input/Output.

## Technologies Used
- Java
- IntelliJ IDEA
- Java I/O

## Concepts Used
- Two-Dimensional Arrays
- Nested Loops
- InputStreamReader
- BufferedReader
- Matrix Multiplication

## Conditions for Matrix Multiplication

The number of columns in the first matrix must be equal to the number of rows in the second matrix.

For example:
- First Matrix: 2 × 3
- Second Matrix: 3 × 2
- Resultant Matrix: 2 × 2

## How to Run (Using IntelliJ IDEA)

1. Open IntelliJ IDEA.
2. Open the Java project.
3. Navigate to `Practical-1`.
4. Open `MatrixMultiplication.java`.
5. Right-click inside the editor.
6. Select **Run 'MatrixMultiplication.main()'**.
7. Enter the dimensions and elements of both matrices.
8. View the resultant matrix.

## Expected Result

The program checks whether matrix multiplication is possible and displays the resultant matrix. If multiplication is not possible, it displays an appropriate message.
