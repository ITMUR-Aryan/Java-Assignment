# Practical 11: Login Form Using Java Swing

## Question
Create a form containing fields name and password respectively, using Applet as a container.

## Technologies Used
- Java
- IntelliJ IDEA
- Java Swing

## Concepts Used
- JFrame
- JLabel
- JTextField
- JPasswordField
- JButton
- ActionListener
- Event Handling
- Swing Components

## How to Run (Using IntelliJ IDEA)

1. Open IntelliJ IDEA.
2. Open the Java project.
3. Navigate to `Practical-11`.
4. Open `LoginApplet.java`.
5. Right-click inside the editor.
6. Select **Run 'LoginApplet.main()'**.
7. Enter your name and password in the form.
8. Click the Submit button.
9. View the confirmation message.

## Expected Result

The program displays a login form containing Name and Password fields with a Submit button. When the user submits the form, a confirmation message is displayed.
