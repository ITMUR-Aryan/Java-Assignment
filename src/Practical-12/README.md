# Practical 12 - CRUD Operations

## Question
Reuse the above form to perform basic database operations (CRUD) using JDBC.

## Language
Java

## Program File
`StudentCRUD.java`

## Data Storage File
`students.csv`

## Description
This program creates a student registration form using Java Swing. It performs four basic CRUD operations: Create, Read, Update and Delete. Student records are stored and managed using a CSV file.
