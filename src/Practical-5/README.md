# Practical 5 - Notepad Application Using Java Swing

## Question
Write a program to create some of the features of Notepad. Use Swing for designing this application.

## Language
Java

## Program File
`Notepad.java`

## Description
This program creates a simple Notepad application using Java Swing. It provides basic features such as New, Open, Save, Save As, Exit, Cut, Copy, and Paste.
