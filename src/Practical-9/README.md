# Practical 9 - Student Registration Portal

## Question
Write a program to create a small portal which contains the registration form of students. Use JDBC.

## Language
Java

## Program File
`StudentRegistration.java`

## Data Storage File
`students.csv`

## Description
This program creates a student registration portal using Java Swing. It provides Create, Read, Update, and Delete (CRUD) operations to manage student records. The entered student details are stored in a CSV file named `students.csv`.
