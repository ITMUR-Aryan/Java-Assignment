# Practical 8 - Storing Form Data Using CSV File

## Question
The input entered in these fields should be stored in the database. Use JDBC connectivity for implementing this program.

## Language
Java

## Program File
`LoginPageN.java`

## Data Storage File
`users.csv`

## Description
This program creates a registration form using Java Swing. It accepts Name and Password from the user and stores the entered information in a CSV file named `users.csv`. It also validates empty fields before saving the data.
